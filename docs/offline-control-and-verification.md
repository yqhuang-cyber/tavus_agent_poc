## HTTP 资源故障

测试进入 Gateway 的资源启用分支，并注入 TavusClient 的模拟 fetch 传输和合成 Tutor；HTTP 只连接本机，供应商实际请求为零。

新增 5 项联测覆盖启动请求断开、创建房间中结束、未知结果阻止新启动、失败房间保留资源额度，以及创建途中 Gateway 关闭。核对凭证撤销、无迟到入房凭证、账本状态和结束后删除 PAL 的顺序。

联测复现并修复：启动 HTTP 请求断开时，原实现只取消开场/请求控制器，资源创建直到返回才看到取消。现在取消立即触发资源 closing 和清理，等待在途 PAL 返回后停止后续房间创建；已在途的房间则记录 ID 并清理。结束路径不会被迟到的启动失败覆盖成开放状态。

## 普通回复阶段计时

会话诊断的 `runs[].timing` 与操作者认证的 `GET /internal/metrics` 提供进程内单调时钟观测：

| 字段 | 含义 |
| --- | --- |
| decision_ms | 当前回复开始至决策调用返回/失败，含超时默认路径 |
| generation_ms | 口语生成调用开始至返回/失败 |
| first_text_ms | 当前回复开始至首个非空文本增量写入 SSE；不含 role 帧 |
| execution_ms | 当前回复处理执行到 finally 退出 |
| cancel_to_execution_end_ms | 主动取消请求到该回复执行退出；未退出保持 null |

汇总按 running/completed/partial/cancelled/failed 分组，分别给出样本数及 nearest-rank p50/p95。空样本为 null，不混同零耗时；范围仅为仍保留的会话轮次，不是长期全站指标。指标不含原文、模型 reason、姓名或凭证。

开场生成、房间创建、STT/TTS/RTC 和真实可听首响还未计入。执行结束或取消确认也不能证明底层供应商停止计算、停止出声或停止计费。首个可听语音、模型 token 用量及费用明确保持 null。20 轮合成 Pi/SSE 探针同时校验并记录 20 个普通回复的计时样本；它们不是生产延迟结果。

## 媒体控制核心

`packages/media/controller.ts` 是独立于浏览器和 Daily 的状态机，输出有顺序和 ID 的命令，由模拟适配记录并以显式结果事件回传。当前未接页面或真实媒体端口。

显式开始前不连接；麦克风拒绝时保持文字辅助且不请求启用麦克风。media-ready 不自动解除静音。打断先输出本地静音命令，再分别请求 Pi 取消和远端打断。两者都确认后仍需显式恢复及一个新的 response ID/递增序号，才请求解除静音；失败保持静音，可显式重连。

房间、会话及 epoch 必须匹配。网络故障先静音/停止采集请求并失效旧 epoch；显式重连不会恢复旧声音或已撤销的麦克风许可。退出是终态，迟到事件和确认不能触发恢复，leave/destroy 失败保持可见。`playback` 表示命令意图，`presentation=unknown`、实际设备释放 `unverified`；没有把模拟命令当作播放/设备回执。

真实适配仍须落实：同步执行本地静音、按连接串行化设备开关、释放迟到获取的 tracks、校验 Daily 事件与 response/inference 的真实归属，并实测声音停止和设备释放。该合同不宣布真实双端打断已经通过。

## 20 段中文/品牌审核准备

`npm run prepare:brand-review` 生成 `.runtime/brand-review.json` 和 Markdown 审核表。`eval/brand-samples.ts` 包含 CN-01～20，覆盖变调、轻声、多音字、数字/日期/量词、四类水平、英文支架与撤除、单个文字纠错、人物一致性和结束/打断。

固定朗读文本与学生对话刺激分开；刺激不能冒充教师实际输出。候选 Face/Voice/Pi/TTS 配置、参考真人资产、实际输出、录制引用、审核人、设备和地区均待填写。20 条的真实输出、中文质量和品牌结果保持未运行/空值，不自造原十维评分锚点，也未生成或上传任何媒体。

## 一键完整离线验收

```sh
npm ci
npm run verify:offline
```

依次运行类型检查、全部测试、20 轮探针、36 场/80 轮矩阵及 20 条审核材料准备；不读取 `.env`，不提供 live 开关。保留继承的代理、TLS 和运行认证配置，实际子脚本使用合成模型或注入模拟接口。

每次生成独立 run ID 和目录。`.runtime/verification-latest.json` 是本次执行索引，具体产物在其 `report_directory`，包括 tests.tap、offline-probe.json、eval-offline.json、brand-review.json/Markdown 和 verification.json。直接单跑旧命令时仍写默认 `.runtime/`；验收应沿索引读取本次产物，不读取默认目录中可能较旧的文件。

开始先把索引置为 running；任一步非零退出、测试失败/取消/跳过/TODO、缺失/错误 run ID 或时间戳报告均阻止整体通过，剩余步骤标记 not-run。报告保留命令、时间、退出码及产物哈希。执行前后对实现、测试、脚本、评测、文档和包文件计算内容指纹，包含未跟踪实现而排除 `.env`、依赖和运行产物；期间源码发生变化则整体失败。每步 90 秒上限，超时或中断终止该次子进程组并记失败。

完整媒体元数据测试需要 ffmpeg/ffprobe；缺少时会出现跳过，完整验收不会把它当作全项通过。单项测试仍可报告自身跳过状态。该入口串行执行一次验收，真实供应商和真人报告继续独立。
