## 已验证的控制路径

Gateway 将每个服务间凭证绑定到单个合成学习者快照，逐轮通过真正的 Pi Agent 完成动作决策与口语生成。教学决策在单独步骤中解析校验，Pi thinking/tool 事件不会作为 `delta.content` 转发。SSE 具有 role、content、stop 和 `[DONE]`，每轮 ID/created 保持一致，处理 HTTP 背压与断开。

两个会话使用同一句输入仍保持资料隔离；同一会话在新增 user 位置重复输入也可正常执行。同位置重试返回 409，不重新生成。输入修订先取消旧工作，已见过的旧版本不能通过迟到重试重新覆盖新版本。回复关联 session、epoch、turn、response、状态/资料/许可版本；不匹配时拒绝输出。

故障注入覆盖：HTTP 断连时 Pi 取消；即使合成供应商忽略取消，迟到文本也不能写出；旧 response ID 的停止请求不能停止后继回复；决策失败不启动 SSE；部分输出失败不伪装完成或自动重放。决策预算超时显式标记默认动作；上层取消不能走默认回复。关闭与到期会撤销凭证，到期会话释放离线并发容量。

除 Pi 自带合成流外，测试还使用实际 Pi OpenAI-compatible provider adapter 对接内存合成 HTTP 响应，校验两步请求、鉴权、模型 ID 和流转换。示例 URL 是虚构测试地址，transport 被替换；这不证明 `tavus-gemma-4` 存在可用端点。异常工具调用无可执行工具，并结束循环；以 JSON/代码围栏等结构开头的口语流被格式校验阻断。该格式校验不等于语义审核。

字幕 reducer 以累计文本替换快照，处理旧 seq/content_index、新旧角色别名、跨房间消息及打断。被打断后的完整生成稿不会把字幕推进到未说完部分。所有字幕的呈现证据均保持 unknown。

模拟 REST 验证了每会话独立 PAL、full/Pi/Face 配置复核、私有房间配置、无正文 200/204、资源 ID 持久记录、end 后 GET 复核、PAL 幂等清理、创建失败补偿、未知创建结果隔离、重启 pending 恢复，以及未知 callback 不触发上游查询。清理只有在状态确认为 ended 后才删除临时 PAL。账本不含 Gateway key、meeting token、对话正文或姓名。
